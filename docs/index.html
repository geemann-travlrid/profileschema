Travlr ID Global Traveler Profile

Version 1.0.0 defines a JSON format for exchanging traveller identity, preferences, accessibility requirements and scoped consent. A supplier can ask whether a room needs a roll-in shower and receive just the authorised fulfilment details.

The first versioned JSON Schema release is v1.0.0. The earlier JSON-LD profile example uses its own version numbering. Integrators adopting the release should validate their data against the versioned JSON Schema.

To propose a change, open an issue with the affected canonical key, the travel use case and a synthetic example. Use fictional travellers, identifiers and grants in public submissions.
